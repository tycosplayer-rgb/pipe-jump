# 水管工大冒险（Pipe Jump）

一款原创的 2D 横版平台跳跃小游戏，灵感来自经典水管工冒险，但使用**完全原创**的画面与命名，不含任何任天堂版权素材、角色名或音乐。

在浏览器中打开即可游玩，无需构建工具。支持键盘与手机触屏；**手机推荐横屏**。

## 在线游玩

**GitHub Pages：** [https://tycosplayer-rgb.github.io/pipe-jump/](https://tycosplayer-rgb.github.io/pipe-jump/)

## 本地游玩

### 方式一：直接打开

用浏览器打开项目根目录下的 `index.html` 即可。

### 方式二：本地静态服务（推荐）

```bash
npx --yes serve .
# 或
python3 -m http.server 8080
```

然后访问提示的本地地址。

## 操作说明

### 键盘

| 按键 | 功能 |
|------|------|
| ← → 或 A D | 左右移动 |
| ↑ / W / 空格 | 跳跃 |
| P 或 Esc | 暂停 / 继续 |
| 空格 / Enter | 开始 / 再玩一次 |

### 触屏（手机 / 平板 · 推荐横屏）

| 屏幕按钮 | 功能 |
|----------|------|
| 左下 ◀ ▶ | 按住左右移动 |
| 右下「跳」 | 点按/按住跳跃（可变高度） |
| 右下「Ⅱ」 | 暂停 / 继续 |
| 点击画布 | 开始 / 暂停 / 结束画面确认 |

- **横屏优先**：页面无顶部标题/操作说明占高度，画布尽量铺满整个可视区域；标题与操作说明在画布开始画面内显示。
- **竖屏**：仍可游玩；「请横过来」为浮动提示（不占布局高度）。
- 触控键在画布内左下/右下；已禁用滚动与双指缩放；音效为低延迟 Web Audio。

## 游戏目标

- 控制绿色帽子水管工跑过一整关。
- 收集金币；顶开「？」砖块可再得金币。
- 从上方踩扁棕色小怪可消灭它们；侧面碰到会受伤。
- 掉进坑里会失去一条命。
- 抵达关底红色旗帜即过关。
- 共有 3 条命；全部用尽可重新开始。

界面文字均为中文；顶部 HUD 显示分数、金币与剩余命数。

## 技术说明

- 纯静态：HTML + CSS + Canvas JavaScript。
- 音效：单一 `AudioContext`（`latencyHint: interactive`），首次手势解锁，预渲染 `AudioBuffer` 播放，避免 `setTimeout` 串联与远程音频加载。
- 触屏：Pointer Events + `touch-action: none`，与键盘共用输入状态。
- 一关完整可通关：地面、砖块、管道、问号砖、坑洞、金币、敌人与终点旗。

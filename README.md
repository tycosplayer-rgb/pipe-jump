# 水管工大冒险（Pipe Jump）

一款原创的 2D 横版平台跳跃小游戏，灵感来自经典水管工冒险，但使用**完全原创**的画面与命名，不含任何任天堂版权素材、角色名或音乐。

在浏览器中打开即可游玩，无需构建工具。支持键盘与手机触屏操作。

## 在线游玩

**GitHub Pages：** [https://tycosplayer-rgb.github.io/pipe-jump/](https://tycosplayer-rgb.github.io/pipe-jump/)

（首次启用 Pages 后可能需要一两分钟生效。）

## 本地游玩

### 方式一：直接打开

用浏览器打开项目根目录下的 `index.html` 即可。

### 方式二：本地静态服务（推荐）

```bash
# 进入项目目录后任选其一：
npx --yes serve .
# 或
python3 -m http.server 8080
```

然后在浏览器访问提示的地址（例如 `http://localhost:3000` 或 `http://localhost:8080`）。

## 操作说明

### 键盘

| 按键 | 功能 |
|------|------|
| ← → 或 A D | 左右移动 |
| ↑ / W / 空格 | 跳跃 |
| P 或 Esc | 暂停 / 继续 |
| 空格 / Enter | 开始游戏、过关或结束后重新开始 |

### 触屏（手机 / 平板）

| 屏幕按钮 | 功能 |
|----------|------|
| 左下 ◀ ▶ | 按住左右移动 |
| 右下「跳」 | 点按/按住跳跃（可变跳跃高度） |
| 右下「Ⅱ」 | 暂停 / 继续 |
| 点击画布 | 在开始 / 暂停 / 结束画面确认 |

触控按钮半透明、位于画布四角，尽量少遮挡画面；已禁用页面滚动与双指缩放干扰。画布会按比例缩放适配手机屏幕。

## 游戏目标

- 控制绿色帽子水管工跑过一整关。
- 收集金币；顶开「？」砖块可再得金币。
- 从上方踩扁棕色小怪可消灭它们；侧面碰到会受伤。
- 掉进坑里会失去一条命。
- 抵达关底红色旗帜即过关。
- 共有 3 条命；全部用尽则游戏结束，可重新开始。

界面文字均为中文；顶部 HUD 显示分数、金币与剩余命数。

## 技术说明

- 纯静态：HTML + CSS + Canvas JavaScript，无框架、无打包。
- 角色、地形、敌人、金币等均为几何色块绘制的复古像素风格。
- 简易 Web Audio 音效（跳跃、金币、踩怪、受伤、过关等蜂鸣）。
- 一关完整可通关：地面、砖块、管道、问号砖、坑洞、金币、敌人与终点旗。
- 触屏：Pointer Events + `touch-action: none`，与键盘共用同一套输入状态。
